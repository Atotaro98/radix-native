Add `Dialog` and `AlertDialog` (Root, Trigger, Content, Title, Description, Close / Action / Cancel) with Radix's sizes, panel, overlay, shadow ring, layout, scroll and animations, in a native `Modal`. Adds the overlay infrastructure: an internal portal host on the root Theme and inside every Modal overlay, and a `safeAreaInsets` Theme prop. A Table inside an `Inset` now aligns its outer cells with the container's padding.
