# Context Menu

```tsx
<ContextMenu.Root>
  <ContextMenu.Trigger style={{ height: 120 }}><Text>Long-press here</Text></ContextMenu.Trigger>
  <ContextMenu.Content>
    <ContextMenu.Item shortcut="⌘ E">Edit</ContextMenu.Item>
    <ContextMenu.Item shortcut="⌘ D">Duplicate</ContextMenu.Item>
    <ContextMenu.Separator />
    <ContextMenu.Item shortcut="⌘ ⌫" color="red">Delete</ContextMenu.Item>
  </ContextMenu.Content>
</ContextMenu.Root>
```

## API Reference

Same as [Dropdown Menu](/components/dropdown-menu). The Trigger is the area that opens the menu with a 700ms long-press, at the touch point.
