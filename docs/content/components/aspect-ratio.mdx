# Aspect Ratio

```tsx
<AspectRatio ratio={16 / 8}>
  <Image
    source={photo}
    resizeMode="cover"
    style={{ width: '100%', height: '100%', borderRadius: 4 }}
  />
</AspectRatio>
```

## API Reference

Inherits from View. No margin or layout props, as in Radix.

| Prop | Type | Default |
|------|------|---------|
| `ratio` | `number` | `1` |
